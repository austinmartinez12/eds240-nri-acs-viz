# Homework #2 (Visualizing FEMA NRI Data)

## purpose

The purpose of this repository was to create a data viz that helps to answer the question, how do FEMA National Risk Index scores for counties in California compare to those in other states? The full assignment description is on the [course website](https://eds-240-data-viz.github.io/course-materials/assignments/HW2.html).
