# Homework #2 and #3

### *(Visualizing FEMA NRI Data) and (Visualizing FEMA NRI x ACS Data)*

## Purpose

The purpose of this repository was to create a data viz that helps to answer the questions, how do FEMA National Risk Index scores for counties in California compare to those in other states and how does climate hazard risk exposure vary across racial / ethnic groups in California? The full assignment descriptions are on the [course website](https://eds-240-data-viz.github.io/assignments.html).

## Data:

The data folder for this repository was put into the .gitignore for storage purposes.

How to access the data:

-   **RAPT Risk Data:** This RAPT data set has more than 100 preloaded layers with data on population, infrastructure and hazards. It can be accessed from this link: <https://experience.arcgis.com/experience/0a317e8998534c30a9b2d3861c814d42/>
-   **American Community Survey (ACS) 1-year Estimates (2023)**: Race and ethnicity population data were obtained from the U.S. Census Bureau’s American Community Survey using the `tidycensus` R package. It can be accessed from this link: <https://www.census.gov/programs-surveys/acs>
